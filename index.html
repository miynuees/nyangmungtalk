아는 선생님들과 짧게 이야기 나눠요.

지금 버전 v0.2.5 (시험판)

처음이신가요?

아래 파일을 받아서 실행하면 설치가 끝나요. 따로 준비할 건 없어요.

냥멍톡 설치하기 처음 쓰는 컴퓨터에

이미 쓰고 계신가요?

지금 것을 지울 필요 없어요. 아래 파일만 실행하면 새 버전으로 바뀌고, 닉네임·친구·대화·모습은 그대로 남아요.

하루 한 번 알아서 새 버전으로 바뀌어요. 지금 바로 바꾸고 싶을 때만 눌러 주세요.
업데이트하기 창 없이 잠깐 만에 끝나요

v0.2.5에서 바뀐 것

  • 내 냥멍이에게도 👑 이름표가 생겼어요. 친구 냥멍이와 같은 높이로 서요.
  • 내 냥멍이도 작업 표시줄 아래로 숨거나 화면 밖으로 나가지 않아요.
  • 겹쳐 있는 친구 냥멍이가 잘 눌려요. 겹친 부분을 누르면 뒤에 있는 다른 프로그램이 눌리던 문제를 고쳤어요. 겹쳐 있으면 앞에 보이는 친구가 잡혀요.
  • 다른 프로그램 창이 냥멍이 위를 덮어도 곧 다시 냥멍이가 맨 위로 올라와요.

v0.2.4에서 바뀐 것

  • 내 냥멍이도 친구들과 놀아요 — 깨어 있는 친구가 옆에 있으면 서로 ♥ ♪ 인사를 하고, 가끔 친구가 내 냥멍이 옆으로 걸어와서 공을 주고받아요. 내 냥멍이를 친구 옆에 끌어다 놓아도 인사해요.
  • 클로드가 일하는 중이거나 말풍선·메뉴가 떠 있을 땐 놀지 않아요.

v0.2.3에서 바뀐 것

  • 냥멍이·친구 냥멍이·집이 조금 작아졌어요 (80%). 친구 냥멍이와 내 냥멍이가 같은 크기예요.
  • 캐릭터 바로 옆 빈 곳을 누르면 뒤에 있는 바탕화면·프로그램이 눌려요. 클릭 범위를 캐릭터에 딱 맞게 줄였어요.
  • 한 줄 메시지 칸에 누구에게 보내는지 나와요. (예: 메시지 보내기 · 워니 님에게)

v0.2.2에서 바뀐 것

  • 한 줄 메시지 칸 오른쪽 위에 × 닫기 버튼이 생겼어요.

v0.2.1에서 바뀐 것

  • 친구 냥멍이끼리 놀아요 — 깨어 있는 친구 둘이 가까이 있으면 가끔 ♥ ♪ 인사를 해요. 친구를 다른 친구 옆에 끌어다 놓으면 바로 인사해요. 몇 분에 한 번은 둘이 가운데서 만나 공놀이나 술래잡기를 하고 제자리로 돌아가요. 노는 중에 만지면 바로 제자리로 돌아와요.
  • 친구 냥멍이 누르는 법이 바뀌었어요 — 한 번 누르면 한 줄 메시지 칸, 두 번 누르면 대화 창이 열려요(집과 같아요). 콕 찌르기는 오른쪽 클릭 메뉴에 있어요.
  • 친구 냥멍이 바로 옆이나 발밑 이름표를 눌러도 잘 눌려요.

v0.2.0에서 바뀐 것

  • 단체방을 바탕화면에 집으로 띄울 수 있어요 — 대화 창에서 단체방에 들어가 위쪽 [🏠 집 띄우기]를 눌러 보세요. 새 메시지가 오면 창문에 불이 켜지고 굴뚝에서 연기가 나요. 그 방 친구가 접속해 있으면 창문에 친구 얼굴이 보여요.
    집을 한 번 누르면 한 줄 메시지 칸, 두 번 누르면 대화 창이 열려요. 오른쪽 클릭하면 집 모양을 일곱 가지 중에서 고를 수 있어요(오두막·버섯집·딸기집·쿠키집·찻주전자집·우유팩집·컵케이크집).
  • 화면에 띄운 친구들이 훨씬 가벼워졌어요 — 컴퓨터 메모리를 예전의 절반 남짓만 써요. 모니터를 두 대 쓰면 친구를 다른 모니터로 끌어다 놓을 수도 있어요.
  • 1:1 대화방의 [나가기]가 [목록에서 지우기]로 바뀌었어요. 지워도 둘 중 누구든 메시지를 보내면 대화방이 다시 생겨요.
  • 친구 목록이 한 줄로 깔끔해졌어요. 접속 중인지는 초록 점으로 보여요.
  • 바탕화면 아이콘이 도트 고양이로 바뀌었어요.
  • 대화방을 만들지 못할 때 괄호 안에 이유가 같이 나와요. 그 글자를 만든 사람에게 알려 주시면 원인을 찾을 수 있어요.
  • 업데이트 뒤 말풍선은 짧게 알리고, 자세한 내용은 이 페이지에서 보게 바꿨어요.

v0.1.7에서 바뀐 것

  • 보냈는지 바로 보여요 — 냥멍이를 두 번 눌러 쓰는 한 줄 칸에서 메시지를 보내면, 칸 위에 초록색 "✓ 보냈어요"가 잠깐 떠요. 인터넷 문제로 못 보내면 "전송을 실패했어요"가 뜨고 쓴 글은 칸에 그대로 남아요.
  • 한 줄 칸 위 안내 글씨가 "메시지 보내기"로 바뀌었어요.

v0.1.6에서 바뀐 것

  • 내 상태를 고를 수 있어요 — 대화 창 위쪽의 📚 수업 중 · 💼 회의 중 · ⏳ 바빠요를 누르면, 그동안 냥멍이가 알림 카드를 쉬고 숫자만 쌓아 둬요. 수업 중은 50분, 회의 중은 1시간, 바빠요는 30분 뒤에 저절로 풀려요. 친구들 화면에도 "📚 수업 중"이 보여요.
  • 읽음 표시 — 내가 보낸 메시지 옆에 분홍 숫자 1이 붙고, 상대가 읽으면 사라져요. (상대도 이 버전이어야 사라져요)
  • 친구를 누르면 바로 대화 — 🐾 친구 목록에서 친구 이름을 누르면 1:1 대화방이 바로 열려요.
  • 안 읽은 개수 — 대화 목록에 점 대신 숫자로 나와요.
  • 이어 쓰기 — 냥멍이를 두 번 눌러 쓰는 한 줄 칸이 보내도 안 닫혀요. 다 쓰면 Esc나 바깥을 눌러 닫아요.
  • 같은 닉네임은 #번호를 붙여 구분하고, 메뉴의 💬 대화는 언제나 대화 목록부터 열려요.

v0.1.5에서 바뀐 것

  • 강아지 얼굴을 다듬었어요 — 코와 주둥이를 작게 하고 입을 연하게 해서, 고양이처럼 동글동글한 얼굴이 됐어요.

v0.1.4에서 바뀐 것

  • 숫자를 누르면 지난 메시지까지 보여요 — 메시지가 여러 개 쌓였을 때 분홍 숫자를 누르면, 최근 것만이 아니라 안 읽은 메시지가 위에서부터 차례로 보여요. 많이 쌓였으면 "앞에 N개 더"라고 알려 주고, 카드를 누르면 대화 창에서 전부 볼 수 있어요. 화면에 띄운 친구 옆 숫자도 똑같아요.
  • 친구를 6명까지 띄울 수 있어요 — 4명에서 늘었어요. 왼쪽에 자리가 모자라면 오른쪽으로 이어서 놓여요.

v0.1.3에서 고친 것

  • 클로드 작업 말풍선이 다시 떠요 — 원래 냥멍이도 깔려 있는 컴퓨터에서, 냥멍톡이 업데이트된 뒤 클로드 작업 말풍선이 안 뜨던 문제를 고쳤어요. 이번 업데이트를 받으면 저절로 다시 떠요.
  • 업데이트되면 바뀐 것을 말풍선으로 알려 드려요.

v0.1.2에서 바뀐 것

  • 닉네임을 바꿀 수 있어요 — 대화 창 맨 위 '내 코드' 칸의 ✏️를 누르면 돼요. 번호는 그대로이고(세니#2344 → 새이름#2344), 친구들 화면의 대화방·친구 목록·띄운 냥멍이 이름표도 같이 바뀌어요. 이미 친구인 사람은 그대로 친구예요. 새 친구에게는 바뀐 코드를 알려 주세요.

v0.1.1에서 바뀐 것

  • 냥멍이가 도트 그림이 됐어요 — 옛날 게임 같은 작은 네모 그림으로 바뀌었어요. 고양이·강아지 무늬 12가지와 소품 5가지 모두 도트로 나와요.
  • 분홍 숫자를 누르면 못 본 말풍선이 다시 떠요 — 메시지를 놓쳐서 숫자가 쌓였을 때 숫자를 누르면, 대화 창을 열지 않고도 못 본 카드들을 냥멍이 위에서 바로 볼 수 있어요. 한 번 더 누르면 접혀요.
  • 화면에 띄운 친구 옆에 숫자가 떠요 — 띄워 둔 친구가 보낸 메시지를 못 보면 그 친구 냥멍이 옆에 숫자가 남아요. 누르면 그 친구 머리 위에 말풍선이 다시 떠요.
  • 친구 냥멍이를 두 번 누르면 바로 한 줄 쓰기 — 대화 창 대신 말풍선 자리에 입력칸이 떠요. 쓰고 엔터 치면 끝. 대화 창은 오른쪽 클릭 → 💬 대화로 열 수 있어요.
  • 모습 고르는 칸이 잘리지 않아요 — 화면이 좁은 컴퓨터에서 무늬·소품이 다 안 보이던 것을 고쳤어요. 넘치면 옆의 ‹ › 를 눌러 넘겨 보면 돼요.
  • 혼자 상자에 쏙 들어가던 동작은 뺐어요.

알아두면 좋은 것

설치할 때 파란 경고창이 뜨면 "추가 정보" → "실행"을 눌러 주세요. 개인이 만든 프로그램이라 뜨는 안내예요.
  • 메시지는 보낸 지 하루가 지나면 사라져요.
  • 수업 중엔 설정 → 대화 오면 말풍선으로 알려주기를 꺼 두면 조용해요.
  • 자세한 쓰는 법은 사용안내에 있어요.
