🐾 냥멍톡

책상 위 작은 냥멍이로 아는 선생님들과 짧게 이야기 나누는 프로그램이에요.

👆 냥멍이 만지기

  • 한 번 클릭: 쓰다듬기
  • 더블클릭 또는 오른쪽 클릭: 메뉴 (💬 대화 · 📅 오늘 · 간식 · ⚙️ 설정 · 👋 종료)
  • 끌기: 원하는 자리로 옮기기 (자리는 기억해요)

💬 처음 대화하기

  • 메뉴 → 💬 대화 → 닉네임을 정하면 세니#2344 같은 내 코드가 생겨요.
  • 서로 코드를 알려 주고 🐾 친구 → 친구 코드로 추가에 넣으면 친구가 돼요.
  • 💬 새 대화에서 친구를 고르면 1:1, 여러 명(최대 4명)을 고르면 단체 대화예요.
  • 메시지는 보낸 지 하루가 지나면 사라져요.

🔔 메시지가 오면

  • 냥멍이 위에 작은 카드가 떠요. 답장을 누르면 바로 답할 수 있고, ×는 읽음으로 닫기, 카드를 누르면 대화 창이 열려요.
  • 카드는 20초 뒤 들어가고, 안 읽은 대화 수는 분홍 숫자로 남아요. 분홍 숫자를 누르면 못 본 카드가 다시 떠요(한 번 더 누르면 접혀요).
  • 수업 중엔 ⚙️ 설정 → 대화 오면 말풍선으로 알려주기를 꺼 두세요.

📌 할 일 띄워 두기 · 바탕화면에만

  • 📅 오늘 → 할 일·일정 탭의 말풍선 고정: 냥멍이 머리 위에 노란 쪽지로 계속 떠 있어요. 동그라미를 누르면 바로 완료, ×로 고정 풀기.
  • ⚙️ 설정 → 화면에 있을 곳을 바탕화면에만으로 바꾸면 다른 창 뒤에 숨어 있다가 바탕화면을 볼 때(Win+D)만 보여요. 친구 냥멍이와 집도 같이 숨어요.

🐶 친구 냥멍이 띄우기

  • 대화 창 → 🐾 친구 → 친구 옆 화면에 띄우기 (최대 6명)
  • 친구 냥멍이는 그 친구가 정한 모습 그대로 나와요. 냥멍톡을 켜 둔 친구는 🟢 초록 점, 꺼 둔 친구는 쿨쿨 자요.
  • 클릭 한 줄 메시지 쓰기 · 더블클릭 대화 창 · 오른쪽 클릭 메뉴(콕 찌르기 · 간식 보내기 · 숨기기)
  • 그 친구가 보낸 메시지는 친구 머리 위 말풍선으로 떠요. 못 봤으면 친구 옆에 분홍 숫자가 남고, 누르면 다시 보여요.

❓ 안 될 때

  • 바탕화면의 냥멍톡 아이콘을 다시 눌러 주세요.
  • 그래도 안 되면 설치 폴더(%LOCALAPPDATA%\SeniWidgets\nyangmungtalk)의 debug.log를 만든 사람에게 보내 주세요.

새 버전이 나오면 하루 한 번 알아서 바꿔 입어요. 불편한 점이나 바라는 점은 편하게 알려 주세요.
